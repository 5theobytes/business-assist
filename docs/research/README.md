# Research sources for niche evaluations

This directory is intentionally limited to a process guide and source templates. The previous automation catalog and research tables were collected in 2025 and did not provide item-level provenance for every claim. They are excluded from the public snapshot until each reusable fact has a verified source, access date, applicable market, and license or attribution review.

Use researched material to form evaluation questions and fictional scenarios, not as current product advice. See [the niche evaluation guide](../evaluation/adding-a-business-niche.md) for the evidence fields, synthetic persona rules, and human review step.

Do not add raw interview notes, participant identifiers, copied paywalled text, secrets, or generated live transcripts here.
