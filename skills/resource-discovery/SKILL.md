# Resource Discovery — Ресурсы

## Цель

Понять, что у пользователя **уже есть** и что он **готов получить**, чтобы план был выполним. Деньги, подписки, API-ключи, хостинг, домены, аккаунты в нужных сервисах.

**Объяви в начале:** «Последний блок перед итоговым планом — давайте посмотрим, что у вас уже есть, чтобы мы не упёрлись в стоп-факторы».

## Используй стиль из `conversational-discovery`

Один вопрос за раз. Бытовой язык. Никаких терминов без объяснения.

## Что нужно выяснить

### 1. Бюджет

Не «сколько денег есть» (это пугает), а **готовность платить за инструменты**:

- «Какую месячную подписку на инструменты вы готовы платить — *до 1000₽, до 5000₽, до 20000₽, не ограничено*?»
- «Это разовая трата или ежемесячная?»
- «Готовы платить за разработку (фрилансер/агентство) или хотите максимально сами?»

### 2. AI-подписки — ключевой блок

**Не спрашивай про "API-ключ" напрямую** — для нетехнаря это пустой звук. Спрашивай про **подписку на ИИ-сервис**, и из ответа уже выводи возможности доступа:

- «У вас есть подписка на ChatGPT, Claude, YandexGPT или GigaChat — пользуетесь чем-то?»
- Варианты: ChatGPT / Claude / YandexGPT или GigaChat / нет, не пользуюсь / не знаю.

Из ответа выводим (внутри, не озвучивая пользователю):
- **ChatGPT (OpenAI)** — аккаунт уже есть, программный доступ оформляется в `platform.openai.com` (отдельная биллинг-страница, нужно положить минимум $5).
- **Claude (Anthropic)** — аккаунт уже есть, программный доступ в `console.anthropic.com`, нужно отдельно пополнить баланс.
- **YandexGPT / GigaChat** — российские провайдеры, доступ через личный кабинет Yandex Cloud / Sber.
- **Нет подписки / не пользуется** — оформим бесплатный или платный тариф как часть проекта.

Если пользователь говорит "не знаю что это" про API-ключ — НЕ объясняй термин. Молча зафиксируй `has_llm_key=false` и переходи дальше; программный доступ оформит разработчик.

### 3. Аккаунты и подписки в нужных сервисах

В зависимости от того, что собираемся делать (определяется по Точке Б), пройдись по релевантному:

- **Telegram:** есть ли свой канал/бот? кто админ?
- **WhatsApp Business:** активен?
- **Google:** есть ли Google-аккаунт (для Sheets/Docs/Drive)
- **CRM:** AmoCRM, Битрикс24 — есть аккаунт, какой тариф
- **Платежи:** ЮKassa, Stripe, Tinkoff — подключено?
- **Рассылки:** Unisender, SendPulse, MailChimp
- **Сайт:** есть ли домен, хостинг, доступ к админке
- **Маркетплейсы:** Wildberries / Ozon — личный кабинет, API

Не спрашивай всё. Спрашивай **только релевантное** под выбранную цель.

### 4. Технические возможности самого пользователя

- «Вы скорее *совсем не технический* (ничего не настраивали сами), *немного умеете* (ставили ботов, копировали код), или *уверенный пользователь*?»

Это влияет на формат дев-спеки и инструкций (что нужно ему делать руками, а что — разработчику).

### 5. Кто будет это поддерживать после запуска

- Сам пользователь
- Кто-то из команды
- Внешний подрядчик
- «Не думал об этом» → подсветим в финальной спеке

## Инструкции по получению ключей

Если у пользователя НЕТ API-ключа — выдай **короткую инструкцию шагами**, по выбранному сервису. Пример для OpenAI:

> **Как получить API-ключ OpenAI (ChatGPT):**
> 1. Зайдите на https://platform.openai.com — это отдельный сайт от обычного chat.openai.com.
> 2. Зарегистрируйтесь / войдите тем же аккаунтом.
> 3. Сверху справа — ваш профиль → "API keys".
> 4. Нажмите "Create new secret key", дайте имя (например, "business-assist").
> 5. Скопируйте ключ (он будет показан один раз!) и сохраните.
> 6. Пополните баланс: профиль → Billing → добавить карту, минимум $5.
>
> Подскажу детальнее, если что-то не получится.

Аналогично для Anthropic (console.anthropic.com), GigaChat, YandexGPT — выдавай по запросу.

**Не вываливай инструкцию, если пользователь не просил.** Сначала спроси: «Подсказать, как получить ключ?»

## Перефразирование

Когда блок ресурсов собран:
> «По ресурсам: бюджет до X₽/мес на инструменты, ключ к OpenAI у вас есть / надо получить, аккаунт в Telegram и Google есть, платежи через ЮKassa уже подключены, поддерживать после запуска будете сами / Маша из команды. Так?»

## Когда переходить дальше

Готово, если ясно:
- Сколько денег в месяц на инструменты
- Какие LLM доступны (или какие надо завести — с инструкцией)
- Какие нужные сервисы уже подключены, к каким нужен доступ
- Кто поддерживает после запуска

Тогда: «Всё, картина полная. Соберу итоговый план — отдельно для вас, чтобы вы понимали, и отдельно для разработчика».
Переходи к скиллу `dual-spec-writer`.

## Запомни

- Бюджет спрашивай как «подписку», не как «бюджет»
- API-ключ объясняй на пальцах
- Инструкцию по получению ключа давай только если просят
- Без ресурсов план = фантазия. Не пропускай этот блок.
