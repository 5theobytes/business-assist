# Optional Claude Code helpers

The files in this directory are optional developer tools for evaluating new business niches. They are not required to install or run BizWare. The app's product prompts live separately in the top-level `skills/` directory.

The niche evaluator separates research, synthetic persona drafting, and review. Research and review agents are read-only. A human maintainer checks source rights and evaluation output before adding a scenario to the regression set.
